# gbfroge

《碧蓝幻想》肉鸽（ソロモナスの賢者 / 转世沙盒）助手，Chrome 扩展。
一个独立窗口：左边实时地图和寻路，右边战斗信息、盘子和导本。

> 本仓库是 [txwzy123/arcarum3-ext](https://github.com/txwzy123/arcarum3-ext) 的 fork，在原版的地图、寻路和导本记录之上做了大量修改。
> 扩展名和页面标识都已改名，可以和原版同时安装。

## 快速下载

**[下载打包版 gbfroge.zip](https://github.com/linyvjinyang/gbfroge/releases/latest/download/gbfroge.zip)**（始终是最新版，历史版本见 [Releases](https://github.com/linyvjinyang/gbfroge/releases)）

## 安装

1. 下载上面的 `gbfroge.zip`，解压到一个不会删掉的位置，得到 `gbfroge` 文件夹。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的「开发者模式」。
4. 点「加载已解压的扩展程序」，选择刚才的 `gbfroge` 文件夹。
5. 把扩展图标固定到工具栏。

Edge 等 Chromium 内核浏览器步骤相同（地址是 `edge://extensions`）。

### 更新

1. 下载新的 `gbfroge.zip`，解压后覆盖原来的文件夹。
2. 在 `chrome://extensions` 里点 gbfroge 的「重新加载」。
3. **刷新游戏页面**（旧页面连不上新版扩展）。
4. 关掉旧的地图窗口，重新打开。

## 使用说明

1. 打开并登录 [碧蓝幻想](https://game.granbluefantasy.jp)，进入肉鸽地图。
2. 点扩展图标打开侧边栏，点「打开地图窗口」。
3. 之后正常玩游戏即可，窗口会跟着游戏自动更新。

窗口顶部有三个页签：**地图**、**导本·盘子**、**设置**。

### 地图

| 操作 | 作用 |
|------|------|
| 鼠标悬浮在格子上 | 显示格子详情；商店格会显示货架、价格和剩余库存 |
| 左键点格子 | 选中这个格子 |
| 右键点格子 | 设为寻路目标（已有目标时再右键别的格子可加途经点） |
| 滚轮 / 左键拖拽 | 缩放 / 平移 |
| 双击 | 回到默认摆放 |
| 左下「定位自己」 | 回到当前位置 |
| 「全图 / 附近」 | 切换看整张图还是只看周围 |
| 地图上的路线按钮 | 生成扫图路线、清除路线 |
| 快捷目标 | 一键寻路到浮空城研究者、Boss、最近的特殊事件、最近的君临者、能消除导本的商店 |

- 窗口顶部会列出本局出现的特殊事件。
- 开局时如果有没去过的浮空城研究者，会自动把它设为第一目标（可在设置里关）。
- 扫图路线默认先向下走到地图边缘，再掉头向上并靠中间走，尽量不走回头路；瘴气出现后不再偏向。
- 商店的寻路权重会随手里的币和商店剩余库存变化，买空的商店按空地算。
- 商店格右上角的小标：`?` 没去过、数字是还剩几件、`空` 是买空了。

### 战斗栏（右侧第一列）

- **敌人**：血量、血条颜色、归类（小怪 / 强敌 / 超强敌 / Boss 等 + 等级）。
  - 绿：这个敌人以前一回合打死过。
  - 黄：血量在本局一回合打死过的最大血量的 3 倍以内。
  - 红：差得很远。
- **击杀预测**：只在第 1 回合显示，用本局记录的"一回合总伤害"和敌人血量比，血条上标出能打掉的部分。
- **上次几回合打死**：同一个敌人上次用了几回合（跨局记录）。
- **预兆 / Boss 机制**：普通预兆、第二天 Boss 的解除条件、最终 Boss 的隐藏"命运"状态，出现时特别提示。
- **队伍**：上面一排是前排，下面一排是后排；后排旁边是按攻击后的 hit 数、奥伤、技伤、总伤害。
- **伤害**：本场实测的单发伤害和上限参考。

大数字用「万 / 亿」显示，鼠标悬浮可以看到完整数值。

### 导本栏（右侧第二列）

- **导本累计**：手里导本的效果合计，debuff 导本单独列在下面。
- **不可重复导本**：用小方块表示，有的会亮。
- **金导本速查**：常用金导本一览。把用不上的拖走就不再显示，可在设置里恢复。
- **角色导本**：按文本格式自动识别，不需要 ID。

两列都可以单独折叠，折叠状态会记住。

### 设置

显示（自适应窗口、底图亮度、空白点、节点 ID、图例）、寻路（各类格子的评分、向下 / 向上扫图、每步奖励）、路线详情、预兆记录、敌人记录、导本速查恢复。

## 数据什么时候更新

扩展**只读游戏自己发出的请求结果**，所以数据是跟着你的操作走的：

| 内容 | 什么时候更新 |
|------|-------------|
| 地图位置、格子变化、队伍血量 | 每走一步、每做一个事件 |
| 回合数、瘴气范围 | 游戏重新读整张地图时（比如打完一场回到地图） |
| 敌人、伤害、预兆 | 战斗里每次行动 |
| 盘子 | 打开编成页面时 |
| 导本 | 获得、移除、购买、打开导本列表时 |
| 商店货架 | 进入那家商店时 |

进入第 1 天第 1 回合时，上一局的战斗记录、商店、队伍血量、手里的导本会自动清掉；预兆记录、敌人记录、导本图鉴跨局保留。

窗口另外每 10 秒会核对一次本地存储的数据，这一步不会向游戏发任何请求。

## 工作方式与隐私

- 和 [Tarou](https://github.com/Waaatanuki/Chrome-Extension-Tarou) 相同的做法：往游戏页面里放一个监听器，挂在游戏自己的 jQuery 上监听"请求成功"。
- **只听不发**：不向游戏服务器发任何请求，不修改游戏的请求和页面，不做任何自动操作。
- 所有数据保存在浏览器本地（`chrome.storage.local` 和扩展页面的 `localStorage`），**不上传、不收集、不联网统计**。
- 扩展只会访问游戏域名和游戏的图片 CDN（用来显示地图底图和图标）。

## 已知限制

- 伤害预测不是公式计算，是拿本局实测的伤害去比敌人血量；角色技能和被动太复杂，算不准绝对数值。
- 以下内容还没有充分实测，可能不准：肉鸽里的编成接口、最终 Boss 三个"命运"状态中的两个的文本、商店默认价格（按 150 币估）、打折商店、事件商店。
- 移动的响应里不带回合数和瘴气，这两项要等游戏重新读整图才更新。
- 界面只有中文。

发现问题欢迎提 [Issue](https://github.com/linyvjinyang/gbfroge/issues)。

## 开发

```text
arcarum3-ext/      扩展本体（加载这个目录即可开发调试）
  content/         游戏页的监听脚本
  background.js    解析抓到的数据，写入本地存储
  map/             独立窗口（地图、战斗、导本、设置）
  shared/          纯逻辑模块（寻路、战斗统计、导本、商店……）
  data/            导本与事件数据库
  test_*.mjs       测试
docs/              接口与寻路说明
tools/             离线分析与打包脚本
```

跑测试（需要 Node.js 18+）：

```bash
cd arcarum3-ext && for f in test_*.mjs; do node "$f" || break; done
```

打包（需要 Python 3，生成 `out/gbfroge.zip`）：

```bash
python tools/package.py
```

原版扩展的详细说明（导本数据库格式、导出与合并等）见 [`arcarum3-ext/README.md`](arcarum3-ext/README.md)，接口说明见 [`docs/map-schema.md`](docs/map-schema.md)。

抓包文件可能包含 Cookie、token、用户 ID，**不要上传**；`.gitignore` 已排除 `captures/` 和 `out/`。
